# 字生万象 / Prototype 01

这是一个面向数字媒体竞赛的可运行互动原型。它把汉字采样为粒子目标点，并通过鼠标扰动、粒子回弹和滚动叙事构成一件可体验的数字文化作品。

## 运行

页面已将 GSAP、粒子逻辑、字体和原创 SVG 图形放入本目录；建议从本目录启动本地静态服务器：

```powershell
py -3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 当前已实现

- 汉字粒子目标采样：火、明、家、字生万象
- 鼠标扰动、暂停、切换字形
- 12 列无空洞 Bento 版式
- GSAP 滚动文字显现、故事列固定、图片缩放和淡入
- 自定义汉字粒子、暂停/连续演绎、全屏欣赏、字形卡 PNG 导出和 16 秒无声 WebM 录制
- 本地 GSAP、字体与原创 SVG 图形；页面不依赖 Picsum 等远程占位图
- 竞赛主题说明、AI 协作边界和后续材料入口

## 面向竞赛的下一步

4. 最终参赛前由团队核对字体、GSAP 与文化资料的展示和打包许可。
